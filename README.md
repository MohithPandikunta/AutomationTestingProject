# Automation Testing Framework

## 📌 Project Overview

This project is a Selenium-based Automation Testing Framework developed using Java, TestNG, and Maven.
The framework automates testing of a web application and follows the Page Object Model (POM) design pattern to ensure maintainability, scalability, and reusability of test scripts.

The framework supports multiple execution environments including Local execution, Selenium Grid, and BrowserStack cloud platform.

---

## 🚀 Tech Stack

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)
* Extent Reports
* Log4j Logging
* Git & GitHub
* BrowserStack (Cloud Testing)

---

## 📂 Project Structure

src/main/java → Page Object Classes
src/test/java → Test Classes
src/test/resources → Configuration files
testng.xml → Test Execution File
pom.xml → Maven Dependencies

---

## ⚙️ Framework Features

* Page Object Model (POM) design pattern
* Cross-browser testing
* Cloud execution using BrowserStack
* Screenshot capture on test failure
* Logging using Log4j
* Test execution using TestNG
* Supports Local, Remote, and Cloud execution

---

## ▶️ How to Run the Project

1. Clone the repository

```
git clone https://github.com/mohithpandikunta/AutomationTestingProject.git
```

2. Import the project as a Maven project in Eclipse.

3. Update configuration values in `config.properties` if required.

4. Run the test suite using:

```
testng.xml
```

---

## 🌐 Cross Browser Testing

This framework integrates with BrowserStack to execute automated tests across different browsers and operating systems in the cloud environment.
